# KSeF XSD Schemas

Place the official KSeF FA(2) XSD schema here to enable full XSD validation.

**Required file:** `FA_VAT_v1-0E.xsd`

**Source:** Polish Ministry of Finance  
https://www.podatki.gov.pl/ksef/dokumentacja-techniczna-ksef/

Without this file, `FA2Validator` runs business-rule checks only (no XSD validation).
The schema file is intentionally excluded from the repository due to copyright.
